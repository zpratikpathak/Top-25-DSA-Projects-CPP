## 🚀 How to Install
1. Ensure you have a C++ compiler installed (e.g., `g++`).
2. Clone the repository or navigate to this folder.
3. Open your terminal in this directory.

## 💻 How to Run
1. Compile the source code:
   ```bash
   g++ -std=c++17 main.cpp -o solution
   ```
2. Execute the compiled file:
   ```bash
   ./solution
   ```
